## Retro Games

### Databases and Catalogs

- [MobyGames](https://www.mobygames.com/) - Credits, release dates and cover art for games across platforms and decades.
- [TheGamesDB](https://thegamesdb.net/) - Open game database with artwork and metadata that frontends can pull from.
- [ScreenScraper](https://screenscraper.fr/) - Metadata and media database used by many emulation frontends.
- [LaunchBox Games Database](https://gamesdb.launchbox-app.com/) - Game metadata and images behind the LaunchBox frontend.
- [Arcade History](https://www.arcade-history.com/) - Notes on arcade games, hardware and release details.
- [Killer List of Videogames](https://www.arcade-museum.com/) - Arcade game database from the International Arcade Museum, with cabinet photos and flyers.
- [Hall of Light](https://hol.abime.net/) - Database of Commodore Amiga games with screenshots and release details.
- [Lemon64](https://www.lemon64.com/) - Commodore 64 game database with reviews and forums.
- [Atarimania](https://www.atarimania.com/) - Catalog of Atari games, hardware and manuals.
- [World of Spectrum](https://worldofspectrum.org/) - Archive and database for the Sinclair ZX Spectrum.
- [Games Database](https://www.gamesdatabase.org/) - Browsable catalog of games by platform.

### Preservation and Archives

- [Internet Archive Software Library](https://archive.org/details/softwarelibrary) - Playable and downloadable archive of old software, including DOS programs.
- [MS-DOS Games Collection](https://archive.org/details/softwarelibrary_msdos) - Browser-playable DOS games on the Internet Archive.
- [Emupedia](https://emupedia.net/) - Non-profit hub for video game preservation, with emulators that run in the browser.
- [Redump](http://redump.org/) - Disc preservation project that documents verified dumps of optical media.
- [No-Intro](https://www.no-intro.org/) - Cartridge dump verification project that maintains DAT files for preservation.
- [Dat-o-Matic](https://datomatic.no-intro.org/) - The database behind No-Intro's verified dump lists.
- [The Strong National Museum of Play](https://www.museumofplay.org/) - Museum with one of the largest video game history collections.
- [Computer History Museum](https://www.computerhistory.org/) - Collections and exhibits on computing and game hardware.
- [Game History Foundation](https://gamehistory.org/) - Non-profit that preserves and shares video game history.
- [Classic Reload](https://classicreload.com/) - Browser-playable classic and abandonware games.
- [MyAbandonware](https://www.myabandonware.com/) - Catalog of old PC games with release data and manuals.

### Emulators and Frontends

- [EZ ROM Patcher](https://ezrompatcher.com/) - Applies IPS, BPS, UPS and xdelta patches to ROM files in the browser.
- [Emulation General Wiki](https://emulation.gametechwiki.com/) - Reference wiki that compares emulators for every platform.
- [RetroArch](https://www.retroarch.com/) - Frontend for emulators, game engines and media players.
- [Libretro](https://libretro.com/) - API and core ecosystem that RetroArch builds on.
- [MAME](https://www.mamedev.org/) - Multi-system emulator focused on documenting arcade and computer hardware.
- [ScummVM](https://www.scummvm.org/) - Runs classic adventure games on modern systems.
- [Dolphin](https://dolphin-emu.org/) - GameCube and Wii emulator.
- [PCSX2](https://pcsx2.net/) - PlayStation 2 emulator.
- [PPSSPP](https://www.ppsspp.org/) - PSP emulator.
- [mGBA](https://mgba.io/) - Game Boy Advance emulator.
- [DOSBox Staging](https://www.dosbox-staging.org/) - Modernized DOSBox fork for DOS games.
- [DOSBox-X](https://dosbox-x.com/) - DOSBox fork aimed at accurate emulation of older PC hardware.
- [EmulatorJS](https://emulatorjs.org/) - Browser-based emulator frontend built on RetroArch cores.
- [Nostalgist.js](https://nostalgist.js.org/) - JavaScript library for running retro console emulators in web pages.
- [Batocera](https://batocera.org/) - Retro gaming operating system that boots from a USB drive or SD card.
- [Recalbox](https://www.recalbox.com/) - Plug-and-play retro gaming system for small computers.
- [EmulationStation](https://emulationstation.org/) - Frontend for browsing and launching emulated games.

### ROM Hacking and Patching

- [ROMhacking.net](https://www.romhacking.net/) - Long-running home of translations, hacks, utilities and documentation.
- [SMW Central](https://www.smwcentral.net/) - Community for Super Mario World hacks, tools and tutorials.
- [PokéCommunity](https://www.pokecommunity.com/) - Forum with a large section on Pokémon ROM hacking.
- [pret](https://github.com/pret) - Disassembly projects that rebuild classic Pokémon and other games from source.
- [RomPatcher.js](https://github.com/marcrobledo/RomPatcher.js) - Open source patching tool that runs in the browser.
- [Nesdev Wiki](https://www.nesdev.org/) - Technical documentation for NES and Famicom development and hardware.
- [Sonic Retro](https://www.sonicretro.org/) - Community documentation and hacking resources for the Sonic series.
- [The Cutting Room Floor](https://tcrf.net/) - Documents unused and cut content found in game files.

### Music and Assets

- [Zophar's Domain](https://www.zophar.net/) - Emulators, documentation and music from retro systems.
- [VGMRips](https://vgmrips.net/) - Chiptune rips from retro systems.
- [VGMusic](https://www.vgmusic.com/) - Large collection of MIDI arrangements of game music.
- [KHInsider](https://www.khinsider.com/) - Soundtrack database covering many consoles and eras.
- [The Spriters Resource](https://www.spriters-resource.com/) - Community archive of sprites ripped from games.
- [The Models Resource](https://www.models-resource.com/) - Community archive of 3D models from games.
- [VGMaps](https://www.vgmaps.com/) - Stitched maps from classic games.
- [Video Game Museum](https://www.vgmuseum.com/) - Screenshots, maps and scans of older games.

### History and Magazines

- [Retropulse](https://theretropulse.com/) - Retro gaming newsletter with news, emulator updates, new releases and fan translations.
- [Hardcore Gaming 101](https://www.hardcoregaming101.net/) - Long-form articles on classic games and series.
- [Retro Gamer](https://www.retrogamer.net/) - Magazine about classic games and the people who made them.
- [Copetti's Architecture of Consoles](https://www.copetti.org/writings/consoles/) - Illustrated technical write-ups of console hardware.
- [Nintendo Life](https://www.nintendolife.com/) - News, reviews and retro coverage of Nintendo games.

### Platform Wikis

- [Sega Retro](https://segaretro.org/) - Wiki covering Sega games, hardware and history.
- [C64-Wiki](https://www.c64-wiki.com/) - Wiki about the Commodore 64.
- [Strategy Wiki](https://www.strategywiki.org/) - Walkthroughs and guides, with many older games covered.

## General Game Databases

- [IGDB](https://www.igdb.com/) - Game database with a free API for developers.
- [IGDB API Docs](https://api-docs.igdb.com/) - Documentation for building on IGDB data.
- [RAWG](https://rawg.io/) - Game discovery site and database.
- [RAWG API](https://rawg.io/apidocs) - API for RAWG game data.
- [Giant Bomb](https://www.giantbomb.com/) - Game wiki and database with a public API.
- [PCGamingWiki](https://www.pcgamingwiki.com/) - Fixes, settings and technical details for PC games.
- [SteamDB](https://steamdb.info/) - Statistics, price history and app data for Steam.
- [GOG](https://www.gog.com/) - Store with DRM-free classics and game pages.
- [Wikidata Video Games](https://www.wikidata.org/wiki/Wikidata:WikiProject_Video_games) - Wikidata project that structures game data as linked open data.
- [VGChartz](https://www.vgchartz.com/) - Sales estimates and platform data.
- [Exophase](https://www.exophase.com/) - Achievement and trophy tracking across platforms.
- [Backloggd](https://www.backloggd.com/) - Game logging and review site.
- [Grouvee](https://www.grouvee.com/) - Collection and backlog tracker.
- [HowLongToBeat](https://howlongtobeat.com/) - Crowdsourced play time database.

## Game Guides and Wikis

- [GameFAQs](https://gamefaqs.gamespot.com/) - Guides, FAQs and boards for games across generations.
- [IGN Wikis](https://www.ign.com/wikis) - Walkthroughs and wikis for major releases.
- [Lutris](https://www.lutris.net/) - Open game manager for Linux with a database of install scripts.
- [MyGamesWiki](https://mygames.wiki/) - English and Chinese game references with an Outbound crafting calculator and a Planet Zoo 2 barrier planner.

## Franchise Databases

- [Aniimopedia](https://theaniimopedia.com/) - Aniimo creatures, items and catch rates.
- [Championspedia](https://thechampionspedia.com/) - Damage calculator and team builder for Pokémon Champions.
- [Combopedia](https://combopedia.com/) - Movelists for fighting game characters.
- [Craftapedia](https://craftapedia.com/) - Minecraft recipes, items, blocks and mobs.
- [Glitch City Wiki](https://glitchcity.wiki/) - Wiki on glitches in Pokémon and other games.
- [JRPGpedia](https://jrpgpedia.com/) - Japanese RPG database covering 4,437 games across 97 platforms and 306 series.
- [Mario Wiki](https://www.mariowiki.com/) - Wiki covering the Mario franchise.
- [Mistriapedia](https://themistriapedia.com/) - Characters, crops, fish and recipes from Fields of Mistria.
- [Palpedia](https://thepalpedia.com/) - Palworld guide to Pals, items, skills and breeding.
- [Pokepedia](https://thepokepedia.com/) - All 1,025 Pokémon with moves, abilities and the type chart.
- [Pokopedia](https://thepokopedia.com/) - Habitats and crafting recipes for Pokémon Pokopia.
- [Project Pokémon](https://projectpokemon.org/) - Research community that documents Pokémon game data and mechanics.
- [Routepedia](https://theroutepedia.com/) - Interactive maps for each of the 44 Pokémon games.
- [SSBWiki](https://www.ssbwiki.com/) - Wiki about the Super Smash Bros. series.
- [Stardewpedia](https://thestardewpedia.com/) - Stardew Valley reference for items, villagers, crops and recipes.

## Speedrunning and Achievements

- [speedrun.com](https://www.speedrun.com/) - Leaderboards and run verification for thousands of games.
- [RetroAchievements](https://www.retroachievements.org/) - Adds achievements to classic games in emulators.

## Mods

- [Nexus Mods](https://www.nexusmods.com/) - Large mod hosting site for many PC games.
- [ModDB](https://www.moddb.com/) - Mod and indie game database.
- [IndieDB](https://www.indiedb.com/) - Indie game profiles and news.
- [GameBanana](https://www.gamebanana.com/) - Mods, skins and tools for many games.
